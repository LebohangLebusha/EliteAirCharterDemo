#  Elite Air Charter — Private Jet Charter Demo

A private jet charter demo website created as a practical project to develop and demonstrate my **web analytics and data analytics skills**.

The project combines my background in **private aviation and sales** with my growing experience in **Google Analytics 4 (GA4), Google Tag Manager, SQL, Power BI, and data analysis**.

##  Project Objective

The primary purpose of this project is to create a realistic website environment where I can practise the complete web analytics lifecycle:

**Define → Implement → Test → Validate → Analyse → Improve**

Rather than working only with pre-existing datasets, I wanted to create my own digital environment and collect data based on how users interact with the website.

## Demo Website

**Elite Air Charter — Private Jet Charter, Tailored Around You**

[Visit the live demo website](https://eliteairchater.lovable.app/?utm_source=chatgpt.com)

The website allows users to explore:

*  Private aircraft and fleet specifications
*  Destinations
*  Charter services
*  Request-a-Quote journey
*  Contact information
*  Aircraft details and specifications

> **Note:** This is a demonstration website. The quote and contact functionality is not connected to a live booking or CRM system.

## Analytics Implementation

I am using the website to practise implementing and analysing:

* Google Analytics 4 (GA4)
* Google Tag Manager (GTM)
* Event tracking
* User interactions
* Page engagement
* Button and link clicks
* Navigation behaviour
* Conversion-related events
* Traffic and acquisition data
* Analytics testing and validation

Through this project, I am gaining practical experience in understanding how to:

1. Define business questions and measurement requirements
2. Identify which user interactions should be tracked

4. Test whether events are firing correctly
5. Validate collected data
6. Analyse user behaviour
7. Translate website activity into meaningful insights
